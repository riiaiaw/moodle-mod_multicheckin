多次签到考勤（mod_multicheckin）安装说明 / Installation notes
============================================================

本压缩包解压后，根目录是 multicheckin/ —— 请保持这个目录名，不要改名、
不要加前缀。

目录名必须是不带 mod_ 前缀的 multicheckin
----------------------------------------
Moodle 的组件名 = 类型 + 目录名。目录名一旦写成 mod_multicheckin，
Moodle 就会推导出组件 mod_mod_multicheckin，然后报「插件不存在」。
反过来，如果 version.php 里的 $plugin->component 写成裸名 multicheckin，
Moodle 会报「无法判断插件类型」。本包已是正确的写法，不要改动。

应该放到哪里
------------
Moodle 5.1 及以上（含 5.2）：
    <站点根>/public/mod/multicheckin/
    （注意：权威 config.php 在 public/ 的上一级）

Moodle 4.x：
    <站点根>/mod/multicheckin/

放好后，目录里应该能直接看到 version.php：
    .../mod/multicheckin/version.php

从旧目录迁移（4.x → 5.1+ 结构）
-------------------------------
cd <站点根>
mv mod/multicheckin public/mod/multicheckin
php admin/cli/upgrade.php        # 或访问「站点管理 → 通知」

数据表不受影响，不需要卸载重装。卸载会连同删除
multicheckin / multicheckin_result / multicheckin_leave / multicheckin_place
/ multicheckin_photoreq 等表，以及学生上传的请假条文件与现场签到照片，
数据不可逆。

可选依赖
--------
- availability_gpsloc   装了就出现「从共享教室库选择」下拉；不装则在下拉
                        位置显示一行提示，指引手填经纬度坐标（共享教室只
                        是表单录入便利，坐标落库后与该插件无关，日后卸载
                        不影响已保存的活动）。

不再依赖 mod_attendance
----------------------
自 v2.0.0 起，version.php 里不再声明任何依赖：标准考勤模块（mod_attendance）
既不要求安装、也不再被回写。此前本包声明过它做「软依赖」，但 Moodle 把
$plugin->dependencies 当成安装门槛——站点若没装那个模块，本插件根本装不上，
而换来的只是一项可有可无的回写。回写已移除，声明也随之去掉：现在只要站点
满足 Moodle 5.2 + PHP 8.3，本插件单独就能安装、升级与运行。
